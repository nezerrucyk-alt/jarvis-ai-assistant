# J.A.R.V.I.S. — плагіни

Плагіни — це звичайні Python-файли, які Jarvis завантажує під час старту. Вони живуть поза `.exe`, тому їх можна додавати, редагувати й видаляти без перезбирання застосунку.

## Де лежать

```
%APPDATA%\Jarvis\plugins\
```

Наприклад: `C:\Users\nezer\AppData\Roaming\Jarvis\plugins\hello.py`.

Після додавання файлу скажи «перезавантаж плагіни» або перезапусти Jarvis.

## Мінімальний плагін

```python
TOOLS = [{
    "type": "function",
    "function": {
        "name": "hello_plugin",
        "description": "Привітатися з користувачем.",
        "parameters": {
            "type": "object",
            "properties": {
                "name": {"type": "string", "description": "Ім'я користувача"}
            },
        },
    },
}]


def run(name, args, ctx):
    if name == "hello_plugin":
        who = (args.get("name") or "сер").strip()
        ctx.log(f"hello_plugin: {who}")
        return f"Привіт, {who}! Це локальний плагін Jarvis."
    return "Невідомий інструмент."
```

## Що доступно в `ctx`

| Поле | Призначення |
|---|---|
| `ctx.confirm(text)` | Запитати підтвердження в користувача перед небезпечною дією. |
| `ctx.log(text)` | Записати повідомлення в лог і показати його в чаті. |
| `ctx.run(name, args)` | Викликати інший інструмент Jarvis (наприклад, `run_command`). |
| `ctx.cfg` | Поточний конфіг застосунку (без службових полів). |
| `ctx.data_dir` | Папка для файлів плагіна: `%APPDATA%\Jarvis\plugin_data\<ім'я>`. |

`run()` може бути звичайною функцією або повертати рядок. Якщо потрібен доступ до мережі, використовуй `requests` — він уже входить у збірку.

## Правила

- Один файл — один плагін. Ім'я файлу унікальне.
- `TOOLS` — список інструментів у форматі OpenAI function calling.
- `run(name, args, ctx)` отримує ім'я інструменту, аргументи й контекст.
- Не зберігай секрети в коді плагіна: використовуй `ctx.cfg` або файли в `ctx.data_dir`.
- Небезпечні дії (видалення файлів, команди PowerShell) проводи через `ctx.confirm`.

## Стартові плагіни

| Файл | Що робить |
|---|---|
| `quick_notes.py` | Нотатки: додати, показати, шукати, видалити. |
| `weather.py` | Поточна погода й прогноз на 5 днів без API-ключа. |
| `currency.py` | Курси НБУ та конвертація валют. |
| `pc_stats.py` | CPU, RAM, диск, аптайм, батарея, топ процесів. |
| `roblox_status.py` | Живий статус Roblox, Studio, Data Store і Game Join. |

## Налагодження

- Лог: `%APPDATA%\Jarvis\jarvis.log`.
- Якщо плагін не завантажився, у логу буде рядок `Плагін <файл> не завантажився: <помилка>`.
- Перевірити синтаксис: `python -m py_compile plugins\hello.py`.
