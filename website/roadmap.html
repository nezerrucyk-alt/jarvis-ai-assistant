03 · Заблоковано

Чесні блокери

Комерційний сертифікат підпису

Платного сертифіката ще немає. SignPath.io безкоштовно підписує відповідні open-source проєкти, але схвалення потребує часу. До того часу перевіряй SHA256SUMS.txt і GitHub-атестації.

Ротація ключа Ashna

Ключ Ashna був показаний у чаті. Його треба відкликати й згенерувати новий у панелі Ashna; старому ключу довіряти не можна.

Дані Home Assistant

Керування розумним домом реалізовано, але потребує URL Home Assistant і довготривалого токена в Налаштуваннях. Без них функцію не перевірити.

Chat API Cursor

Cursor не має підтвердженого публічного chat API. Експериментальний провайдер потребує сумісного endpoint у cursor_api_url, тому він не ввімкнений за замовчуванням.

04 · Долучитися

Як допомогти

  • Перевір збірку на своїй ОС і залиш чесний відгук із системою й версією.
  • Повідомляй про баги з логами з папки даних Jarvis, але спершу прибери API-ключі й особисті дані.
  • Напиши плагін, поділись ним в issue або покращ документацію через pull request.
  • Якщо ти підтримуєш OSS-сервіс підпису або можеш допомогти із сертифікатом — відкрий issue.
