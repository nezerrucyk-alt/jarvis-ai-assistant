# Сторінка завантаження J.A.R.V.I.S.

Статична багатоплатформна сторінка. GitHub Actions автоматично підставляє адресу публічного репозиторію та розгортає index.html у GitHub Pages після оновлення основної гілки.

Посилання на завантаження ведуть на останній GitHub Release. Публікуйте тег версії виду v1.0.0, щоб Actions зібрав Windows, macOS, Linux і Android APK та прикріпив їх до релізу.
