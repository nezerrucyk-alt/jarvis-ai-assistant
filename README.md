# J.A.R.V.I.S.

Персональний ШІ-помічник із голосовим керуванням, режимом кодера та підтримкою кількох AI-провайдерів.

## Завантаження

[Відкрити сторінку Jarvis](https://nezerrucyk-alt.github.io/jarvis-ai-assistant/) або переглянути останні збірки у вкладці Releases GitHub:

- Windows — JARVIS-Windows.exe
- macOS — JARVIS-macOS.zip
- Linux — JARVIS-Linux.tar.gz
- Android — JARVIS-Android.apk

Для сторінки завантаження використовується GitHub Pages. Настільні програми збираються на цільовій ОС, Android APK — через Buildozer/Kivy. PyInstaller не є крос-компілятором: збірки Windows, macOS і Linux виконуються окремо на відповідних раннерах GitHub Actions.

## Android

Застосунок має два варіанти роботи:

1. **На телефоні** — чат і режим кодера через OpenAI-сумісний API. Ключ зберігається у приватному сховищі застосунку на пристрої.
2. **Через Jarvis на ПК** — введіть URL, токен і SHA-256 відбиток, які показує кнопка Android у настільному застосунку. Обидва пристрої мають бути в одній Wi-Fi мережі. Перед кожним запитом Android перевіряє відбиток TLS-сертифіката. У цьому режимі телефон отримує відповіді чату, але не може запускати команди на ПК.

Сертифікат і токен генеруються при ввімкненні підключення. Вимикайте його в Jarvis, коли воно більше не потрібне.

## Запуск із вихідного коду

Потрібен Python 3.11 або новіший. Встановіть залежності з requirements.txt, потім запустіть jarvis.py.

Android-застосунок збирається через Buildozer у Linux/macOS або WSL. Початкове налаштування завантажує Android SDK/NDK і може потребувати кількох хвилин.

Збірка macOS не має підпису Apple, а Android APK для релізу збирається у debug-режимі. Для Play Store потрібна окрема підписана AAB-збірка.
